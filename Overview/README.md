# Project Overview

**Secure Access Management System using ESP32 Micro Web Server and QR Authentication**

---

## Project Description

This project consists of the design and implementation of a secure electronic access control system using an ESP32 DevKit V1 as the core processing unit.

The system operates as a Micro Web Server (MWS), allowing users to access a locally hosted web interface by scanning a QR code generated by the device. Through this interface, authorized users enter a PIN, which is validated directly inside the ESP32.

If authentication is successful, the system activates a physical actuator (relay or servo motor) to simulate door unlocking. The system also incorporates basic cybersecurity mechanisms such as brute-force protection and network isolation.

---

## Objective

The main objective of this project is to develop a secure, autonomous, and embedded access control system that:

* Hosts its own web server.
* Authenticates users via PIN validation.
* Controls a physical locking mechanism.
* Implements basic cybersecurity protections.
* Operates independently without external cloud services.

---

## Project Feasibility

The project is technically and economically feasible because:

* The required hardware components are affordable and available.
* The ESP32 integrates Wi-Fi and processing capabilities in a single board.
* The development framework (Arduino C++) is stable and well-documented.
* The system scope is aligned with the academic timeline.
* The team has prior knowledge in embedded systems, networking, and programming.

The prototype can be fully demonstrated using a breadboard-based setup.

## Hardware Components and Justification

### 1. Microcontroller

**ESP32 DevKit V1**

* Dual-core processor with integrated Wi-Fi and Bluetooth.
* Capable of hosting a web server locally.
* Provides sufficient GPIO pins for actuator and LED control.
* Low cost and energy efficient.

### 2. Actuator – Relay Module (5V, Single Channel)

* Used to simulate the electronic locking mechanism.
* Allows safe switching of higher voltage loads if required.
* Electrically isolates control logic from power circuitry.

### 3. Actuator – Micro Servo Motor SG90

* Used to simulate mechanical lock movement.
* Provides visual and physical demonstration of access control.
* Easy PWM control via ESP32 GPIO.

### 4. Status Interface – LEDs (Red and Green)

* Green LED: Access granted.
* Red LED: Access denied.
* Provides immediate visual feedback to the user.

### 5. Passive Components – 220Ω Resistors

* Protect LEDs from overcurrent.
* Ensure stable and safe operation.

### 6. Connectivity Infrastructure

* Breadboard and jumper wires for rapid prototyping.
* Micro-USB cable for power supply and firmware upload.
