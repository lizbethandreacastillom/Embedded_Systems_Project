# Especificaciones de Hardware - Sprint 1

## Pinout del ESP32
- **LED Verde (Éxito):** GPIO 2
- **LED Rojo (Denegado):** GPIO 4
- **Relevador/Servo:** GPIO 18
- **Entrada de Voltaje:** 5V via USB
